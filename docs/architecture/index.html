4. 시퀀스: 노트 저장 / 삭제

서버 응답을 받은 뒤에 로컬 상태를 갱신한다 (낙관적 업데이트 없음). 에러는 호출한 컴포넌트에서 console.error로 처리.

sequenceDiagram
  actor U as 사용자
  participant E as NoteEditor
  participant L as NoteList
  participant C as NotesContext
  participant A as api/notes.ts
  participant S as json-server

  U->>E: 저장 클릭
  E->>E: 제목 검증 (빈 값이면 console.error 후 중단)
  E->>E: setSaving(true)
  alt isCreating
    E->>C: createNote(title, content)
    C->>A: api.createNote({title, content})
    A->>S: POST /notes (createdAt, updatedAt 포함)
  else 수정
    E->>C: updateNote(id, {title, content})
    C->>A: api.updateNote(id, updates)
    A->>S: PATCH /notes/:id (updatedAt 갱신)
  end
  S-->>A: Note JSON
  A-->>C: Note
  C->>C: setNotes(append / map)
  C-->>E: resolve
  E->>E: onDone() → App.isCreating = false
  E->>E: setSaving(false)

  Note over U,S: 삭제 (NoteList → NoteItem 삭제 버튼)
  U->>L: NoteItem 삭제 클릭 (onDelete)
  L->>L: handleDelete(id) — try/catch, 실패 시 console.error
  L->>C: deleteNote(id)
  C->>A: api.deleteNote(id)
  A->>S: DELETE /notes/:id
  S-->>A: ok
  A-->>C: resolve
  C->>C: setNotes(filter)
