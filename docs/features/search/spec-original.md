# 노트 검색 기능

## 요약

사이드바에서 노트를 제목/본문으로 검색하는 기능.
검색어 입력 후 Enter로 실행, 매칭되는 노트만 목록에 표시.

## 핵심 동작

### 검색 입력
- 사이드바 상단(NoteList 위)에 검색 입력 필드 배치
- Enter 키로 검색 실행 (실시간 필터링 아님)
- 빈 검색어 시 전체 노트 표시

### 검색 로직
- 검색 대상: 제목(title) + 본문(content)
- 대소문자 구분 없음 (case-insensitive)
- 부분 일치 (contains)

### 태그 필터와의 조합
- 검색어와 태그 필터는 AND 조건으로 동시 적용
- 예: "react" 검색 + "study" 태그 선택 → 두 조건 모두 만족하는 노트만 표시

### 검색 초기화
- 검색 입력 필드의 X 버튼 또는 빈 문자열 Enter로 초기화
- 초기화 시 전체 노트 표시 (태그 필터는 유지)

## 제약 사항

| 항목 | 규칙 |
|------|------|
| 검색 대상 | 제목 + 본문 (태그 제외) |
| 검색 방식 | Enter 키로 실행 |
| 대소문자 | 구분 없음 |
| 매칭 방식 | 부분 일치 (contains) |
| 태그 필터 조합 | AND 조건 |
| 미지원 | 정규식, 퍼지 검색, 검색 하이라이트, 검색 히스토리 |

## Out of Scope

- 정규식 검색
- 퍼지/유사어 검색
- 검색어 하이라이트
- 검색 히스토리
- 태그 내용 검색 (태그 필터로 대체)
- 실시간 타이핑 필터링
